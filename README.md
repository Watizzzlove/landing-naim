# J-TALENT® — Programmatic Recruitment & Hiring Agency Landing

> Интерактивный бруталистский прототип лендинга для агентства по найму персонала в эстетике [j-vers.com](https://www.j-vers.com/) (Obys Agency style).

---

## О проекте

Лендинг разработан как готовый интерактивный прототип для презентации заказчику на бирже с последующим бесшовным переносом на **Tilda Publishing** (Zero-блоки + модуль «Потоки» для SEO-статей).

### Ключевые возможности:
- **Hero-экран с 3D-графикой:** Прозрачная шапка, фиксированная кнопка полноэкранного бургер-меню и медленно вращающаяся 3D-модель (Three.js Torus Knot).
- **Stacking Cards:** 4 складывающиеся карточки («Охват», «Кастомизация», «Аналитика данных», «Полный цикл») с векторной бруталистской графикой.
- **Алгоритмический найм:** Секция со скролл-привязанным вращением 3D-сферы и последовательным всплытием тезисов с трех сторон.
- **4 Шага к результату:** Трехколоночная сетка: слева бесшовная 3D-фигура (вращается только при скролле), по центру вертикальная шкала с чекпоинтами (01–04), справа просторные карточки этапов.
- **Интерактивный калькулятор найма:** Динамический расчет сроков, бюджета, гарантии и охвата резюме (`~4 500 резюме`) без лишних рамок.
- **База знаний (SEO-блог):** Bento Grid верстка с векторными иллюстрациями под требования SEO.
- **Циклопический заголовок FAQ:** Монументальный заголовок `FAQ` на пол-экрана и плавное раскрытие на CSS Grid.
- **Конверсионная форма:** Контрастные кобальтовые акценты, современный минималистичный UI.

---

## Стек технологий
- **HTML5 & CSS3**
- **Tailwind CSS** (через CDN с кастомной палитрой)
- **Three.js** (кинетические 3D-сцены)
- **Lenis Smooth Scroll** (шелковистый agency-скролл)
- **Lucide Icons**
- **Google Fonts:** `Syne` (акцидентные заголовки) + `Inter` (текст)
