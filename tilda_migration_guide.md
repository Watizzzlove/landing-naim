# Инструкция по бесшовному переносу в Tilda и ответ заказчику

Данный документ описывает, как перенести интерактивный прототип из `index.html` на платформу **Tilda** с минимальными трудозатратами, без «костылей» и с полным сохранением вау-эффекта и SEO-потенциала.

---

## 1. Карта блоков: Прототип ➔ Tilda

| № | Секция прототипа | Реализация на Tilda | Почему именно так (без костылей) |
|---|---|---|---|
| **01** | Верхний тикер (Ticker) | **Zero-блок** или блок **T228** | Простая бегущая строка на CSS или встроенная Tilda-анимация. |
| **02** | Меню (Header) | **Zero-блок** (фиксированный) или **ME401** | Рекомендуется Zero-блок с `Fixed` позиционированием, чтобы сохранить моноширинные бейджи `[01]` и стиль кнопки. |
| **03** | Hero-экран | **Zero-блок** (100% высота экрана `100vh`) | Крупная типографика (Syne / Space Grotesk), адаптив под 5 брейкпоинтов (1200, 960, 640, 480, 320 px). |
| **04** | **Stacking Cards** (Складывающиеся карточки) | **4 отдельных Zero-блока + блок T123 (CSS)** | **Секрет чистого переноса:** Каждая карточка верстается в своём Zero-блоке одинаковой высоты. В блоке T123 прописывается простой CSS-класс `position: sticky; top: 120px;`. Карточки ложатся друг на друга нативно в браузере, без глюков мобильного скролла! |
| **05** | **Центральная 3D-секция** (Three.js Canvas) | **Zero-блок + HTML-элемент (T123)** | В Zero-блок добавляется контейнер с HTML-кодом `<canvas id="kinetic-canvas"></canvas>`. В `<head>` сайта подключается lightweight Three.js через CDN. Скрипт вращения занимает всего 30 строк кода. |
| **06** | **4 Шага (Workflow)** | **Zero-блок со Step-by-Step (SBS)** или 2 колонки | Левая колонка с фиксацией через `Fix while scroll`, правая — последовательно сменяющиеся карточки этапов. |
| **07** | **Калькулятор найма** | **Блок T123 (HTML/JS виджет)** или формы **BF301** | Проще всего вставить готовый JS-код калькулятора прямо в HTML-элемент Zero-блока. Все стили уже настроены под дизайн. |
| **08** | **SEO-Блог (База знаний)** | **Стандартный модуль: «Потоки» (Feeds)** | **ВАЖНО ДЛЯ SEO:** Не верстать статьи в Zero-блоках! Потоки Тильды автоматически генерируют ЧПУ-ссылки, микроразметку `Schema.org/Article`, AMP/турбо-страницы и `sitemap.xml`. |
| **09** | **FAQ (Вопросы и ответы)** | **Стандартный блок TX16N** (со стилизацией) | Имеет нативную разметку `FAQPage` для сниппетов поисковых систем (Яндекс / Google). |
| **10** | **Подвал (Footer)** | **Zero-блок** | Крупный текст email и навигационные ссылки для SEO-перелинковки. |

## 2. Готовые сниппеты кода для Tilda (T123)

### А. Эффект Stacking Cards (Складывающиеся карточки)
Присвойте 4 Zero-блокам карточек одинаковый класс (например, `tilda-stack-card`) в настройках блока или через селекторы ID:

```html
<!-- Вставить в блок T123 на странице с карточками -->
<style>
  /* ID или класс блоков с карточками */
  #recXXXXXXXX1, #recXXXXXXXX2, #recXXXXXXXX3, #recXXXXXXXX4 {
    position: sticky !important;
    top: 110px !important;
    z-index: 10;
  }
  #recXXXXXXXX2 { top: 130px !important; z-index: 11; }
  #recXXXXXXXX3 { top: 150px !important; z-index: 12; }
  #recXXXXXXXX4 { top: 170px !important; z-index: 13; }
</style>
```

### Б. Подключение 3D-фигуры в Zero-блок
В Zero-блок добавьте элемент **HTML**:
```html
<div style="width: 100%; height: 420px; position: relative;">
  <canvas id="tilda-3d-canvas" style="width: 100%; height: 100%;"></canvas>
</div>

<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<script>
  (function() {
    const canvas = document.getElementById('tilda-3d-canvas');
    if (!canvas) return;
    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(45, canvas.clientWidth / canvas.clientHeight, 0.1, 1000);
    camera.position.z = 4.5;
    const renderer = new THREE.WebGLRenderer({ canvas: canvas, alpha: true, antialias: true });
    renderer.setSize(canvas.clientWidth, canvas.clientHeight);

    const knotGeo = new THREE.TorusKnotGeometry(1.1, 0.28, 100, 16);
    const knotMat = new THREE.MeshBasicMaterial({ color: 0x0038FF, wireframe: true, opacity: 0.85, transparent: true });
    const mesh = new THREE.Mesh(knotGeo, knotMat);
    scene.add(mesh);

    function animate() {
      requestAnimationFrame(animate);
      mesh.rotation.x += 0.006;
      mesh.rotation.y += 0.009;
      renderer.render(scene, camera);
    }
    animate();
  })();
</script>
```
